# Futures TP/SL & Plan Order Management Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add futures Take-Profit/Stop-Loss and trigger (plan) order management to bitget-core — place TP/SL on existing positions, place stop-market trigger orders, modify/cancel/query them, and document preset-on-open.

**Architecture:** Four new `ToolSpec`s appended to `registerFuturesTradeTools()` in `bitget-core`, each multiplexing related Bitget endpoints via a `mode`/`status` discriminator (matching existing `futures_cancel_orders`/`futures_get_orders` style). Endpoint paths centralized in `api/futures.ts`. An in-process mock (`bitget-test-utils`) gains a `planOrders` store and 7 routes so vitest round-trips work offline. Tools flow automatically into the MCP server, CLI, and generated skill references.

**Tech Stack:** TypeScript (ESM/NodeNext, strict, `noUncheckedIndexedAccess`), tsup, vitest, pnpm monorepo (`workspace:*`).

## Background for the implementer (read first)

- **Build order matters.** Consumers import `bitget-core` from its built `dist/`, not source. After editing core or test-utils you MUST `pnpm -r build` before running consumer tests, the smoke test, or `gen-references`. For the `bitget-core` package's own vitest, build `bitget-core` and `bitget-test-utils` first.
- **Imports use `.js` extensions** even in `.ts` source (NodeNext). e.g. `import { x } from '../api/index.js'`.
- **Tool files** live in `packages/bitget-core/src/tools/`. The file you edit is `futures-trade.ts`. It already imports the helpers you need on line 2 and `FUTURES_ENDPOINTS` from `../api/index.js` on line 4, and `ValidationError` on line 5. It defines a local `normalize(response)` helper and `registerFuturesTradeTools()` returning a `ToolSpec[]` array — you append new objects to that returned array.
- **Helpers** (`tools/helpers.ts`): `asRecord`, `readString`, `readNumber`, `readBoolean`, `readStringArray`, `requireString`, `assertEnum(value, key, values)` (no-ops when value is undefined), `ensureOneOf(args, keys, message)`, `compactObject(obj)` (drops undefined/null values). String-encoded JSON is accepted for array params via `readStringArray`.
- **Rate limit:** sibling order tools use `privateRateLimit('<tool_name>', 10)`. Match that.
- **Response wrapping:** every handler returns `normalize(response)` where `response` is the result of `context.client.privatePost/privateGet`.
- **Test file** `tests/tools/futures.test.ts` uses **double quotes** locally (pre-dates the single-quote reformat). Match double quotes when adding tests to that file. It boots a `MockServer`, sets env, and builds tools with `config = loadConfig({ modules: "futures", readOnly: false })`. Use the existing `getTool(name)` helper and `server.getState()` to inspect mock state.
- **Mock state** (`bitget-test-utils/src/server/state.ts`): `MockState` is an interface; `createEmptyState()` constructs it; `server.reset()` rebuilds via `createEmptyState()` between tests, so anything added to both the interface and `createEmptyState()` is auto-reset. `nextId(state, prefix)` returns `prefix` + 10-digit zero-padded counter.
- **Mock routes** (`bitget-test-utils/src/server/routes/futures-trade.ts`): `router.register(METHOD, path, (req, body, query, state) => result)`. `body` is the parsed POST JSON (`Record<string, unknown>`); `query` is a `URLSearchParams`. Return the raw `data` payload — the router wraps it in Bitget's `{ code, msg, data }` envelope.

```ts
    const orderId = body['orderId'] as string;
    const order = state.planOrders.get(orderId);
    if (!order) {
      throw new Error(`Plan order ${orderId} not found`);
    }
    if (body['triggerPrice'] !== undefined) {
      order.triggerPrice = body['triggerPrice'] as string;
    }
    if (body['size'] !== undefined) {
      order.size = body['size'] as string;
    }
    order.uTime = Date.now()
      .toString();
    return {
      orderId
    };
  });

  router.register('POST', '/api/v2/mix/order/modify-plan-order', (_req, body, _query, state) => {
    const orderId = body['orderId'] as string;
    const order = state.planOrders.get(orderId);
    if (!order) {
      throw new Error(`Plan order ${orderId} not found`);
    }
    if (body['triggerPrice'] !== undefined) {
      order.triggerPrice = body['triggerPrice'] as string;
    }
    if (body['newSize'] !== undefined) {
      order.size = body['newSize'] as string;
    }
    order.uTime = Date.now()
      .toString();
    return {
      orderId
    };
  });

  router.register('POST', '/api/v2/mix/order/cancel-plan-order', (_req, body, _query, state) => {
    const now = Date.now()
      .toString();
    const orderIdList = body['orderIdList'] as {
      orderId: string;
    }[] | undefined;
    if (orderIdList && orderIdList.length > 0) {
      const ids = orderIdList.map((item) => item.orderId);
      ids.forEach((id) => {
        const o = state.planOrders.get(id);
        if (o) {
          o.status = 'cancelled';
          o.uTime = now;
        }
      });
      return {
        successList: ids.map((id) => ({
          orderId: id
        })),
        failureList: []
      };
    }
    const symbol = body['symbol'] as string | undefined;
    for (const o of state.planOrders.values()) {
      if (o.status === 'live' && (!symbol || o.symbol === symbol)) {
        o.status = 'cancelled';
        o.uTime = now;
      }
    }
    return {
      successList: [],
      failureList: []
    };
  });

  router.register('GET', '/api/v2/mix/order/orders-plan-pending', (_req, _body, query, state) => {
    const symbol = query.get('symbol');
    return [...state.planOrders.values()].filter((o) => o.status === 'live' && (!symbol || o.symbol === symbol));
  });

  router.register('GET', '/api/v2/mix/order/orders-plan-history', (_req, _body, query, state) => {
    const symbol = query.get('symbol');
    return [...state.planOrders.values()].filter((o) => o.status !== 'live' && (!symbol || o.symbol === symbol));
  });
```
